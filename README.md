One sentence pitching a bizarre startup idea that sounds absurd until it sells, built for the [make.fun bounty](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a).

## The entry

> We rent out professional criers for strangers' funerals, because grief is the one subscription nobody cancels — and our five-star tears already outsell the florist.

164 characters, one sentence. The pitch sounds ridiculous at first glance — hiring strangers to cry at a funeral — and real by the second: grief is universal, recurring, and nobody ever cancels on it, so a five-star crying service is a subscription business hiding inside a taboo.

## How to run

Requires Node.js 22.

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (override the directory with `OUTPUT_DIR` for local testing). `main.ts` enforces the bounty gate itself: the entry must be 1–200 UTF-8 characters and not only whitespace.

## Files

- `main.ts` — the entrypoint; writes the one-sentence pitch to `/output/entry.txt`.
- `.makefun/owner.json` — payout wallet for the bounty owner.
- `LICENSE` — MIT.
